检定规则:
  通用掷骰:
    基础: "系统自动通过 _.random(1, 100) 掷 1d100 并写入 stat_data._rollLog；检定面板展示结果；目标 ≤ 技能/属性 = 成功"
    成功档次:
      - 大成功: 投出 1~5（等效投出 1），不消耗幸运，可直获核心线索或关键时刻逆转
      - 极难成功: 投出 ≤ 技能值/5，突破剧情阻碍、附带意外好处
      - 困难成功: 投出 ≤ 技能值/2，成功且比预期更快或更优雅
      - 普通成功: 投出 ≤ 技能值，达成预期目标无额外
      - 失败: 投出 > 技能值，达不成目标
      - 大失败: 投出 96~100，不仅失败还引爆意料外的坏结果（对手察觉、道具损毁、心神 额外验定等）

  奖励骰与惩罚骰:
    奖励骰: "掷一个十位骰（0~9）×10 + 两个个位骰（0~9），取个位最小值 → 总投骰值 = 十位 + min(u1, u2)。若 00 视为 100，01 视为 1。"
    惩罚骰: "同理掷两个个位骰取最大值 → 总投骰值 = 十位 + max"
    常见触发:
      奖励骰(+N): HO 特长（<user> 读书/历史/交涉检定；严七 潜行/欺瞒；云鹤来 侦查/察言观色）；工具齐全、充分准备、NPC 协助
      惩罚骰(-N): 黑暗/受伤/紧急施术/无夜间视力；以非本职使用高难技能；受监视、恐吓、对峙高级敌人

  幸运值与强投（7 版希望的两种翻盘，区别于单纯重投）:
    幸运值翻盘:
      说明: "失败后玩家可自报 `/幸运` 或 `/幸运 N` 花费幸运值将投出值降至 ≤ 目标即判成功。"
      规则:
        - 恰够翻盘 = 投出值 - 目标；须主角当前幸运 ≥ 该值方可用
        - 翻盘后计为"普通成功"，不享极难/困难档次
        - 花费的幸运值由 主持 在本轮 <UpdateVariable> delta 扣减；幸运回 1d3/章·关键剧情
      示例: "你掷潜行 投出 62 目标 55 失败；`/幸运` 翻盘花 7 点幸运 → 55 恰好，普通成功。"
    强投（Pushed Roll）:
      说明: "失败后玩家可 `/强投`：再投一次，自动带 1 惩罚骰。"
      规则:
        - 重投成功即得原档次成功；二番失败则后果远重（主持 选 代价/误导/迟滞 更严的一档升一级）
        - 同一检定仅可强投一次；幸运与强投二选一，不可叠加
        - 强投适合希望叙事"咬着牙再试一次"的紧张瞬间；主持 须让二番失败的代价兑现
      示例: "攀墙取露一次失败 → `/强投` 带惩罚骰重投；再败则不慎坠伤 1d6 气血 且惊动守兵。"

  对抗检定:
    - 玩家与 NPC 同掷骰，成功档次更高者胜
    - 同档则比技能值（取高者胜）；值相同则为僵持/平手
    - 双方皆失败 = 无进展
    - 典型对抗：交涉/说服/欺瞒对峙、潜行 vs 侦查、格斗 vs 闪避

  心神 检定（自动掷骰判定）:
    流程:
      1. 主持 判定触发 心神 损失的恐怖源等级（见 心神 损失事件条目）
      2. 玩家或 主持 投 1d100，≤ 心神 当前值 = 成功
      3. 成功：损失「预计较小值」（通常为源损失值）
      4. 失败：损失「预计较大值」（通常为源损失值的 1.5~2 倍）
      5. 大成功(≤5)：不受 心神 损失且可能获得瞬时"窥破一角"线索
      6. 大失败(96~100)：直接触发失魂发作检定
    单次损失≥5 → 失魂发作：掷 1d10 查失魂表，演绎 1d10+1d4 回合
    周期累计损失≥上限的 1/5（默认 12）→ 持久失魂，进入疗养/隐居/逃离等转向带

  失魂发作表现表（1d10）:
    1: 假性昏迷/茫然失神
    2: 强迫性小动作（反复计数、咬指甲、撕纸张）
    3: 谵妄·眼见不存在之物或听见不存在的声音
    4: 妄想·被害或自认被选中的
    5: 阵发性恐惧·对特定物象（槐树、血、铜钱、太监）
    6: 失语或反复喃喃同一句
    7: 短暂攻击性爆发
    8: 嗜睡/瘫软无反应
    9: 强迫性禁忌行为（食生食、舔血、自残）
    10: 逃窜·以最快安全离源

  常用技能一览:
    - 翻检文牍: 查奏折、皇城司封口记录、应朝遗书
    - 历史: 推应太祖/北燕权斗/前朝方士
    - 交涉: 朝堂接旨、说服净白/钱庄东家、安抚旧部
    - 潜行: 夜潜槐树、护国寺后殿、爬墙取露
    - 欺瞒: 假身份、骗桐淮帮众、对聂朝夕周旋
    - 术数: 解读坛蛊/坛仙、铜钱坠、感应仙槐
    - 侦查: 发现黄符异常、察觉桐淮帮众伪装
    - 察言观色: 识破太监/钱庄东家/护国僧的隐瞒

  输出格式:
    "在叙述中以括号标注："
    "【检定｜技能名 XX｜投出 YY｜成功/失败/大成功/困难成功/大失败】"
    "例：【检定｜侦查 45｜投出 22｜困难成功】你一眼看见黄符上不该出现的纹路。"

  与检定引擎联动（新 · 显式掷骰协议）:
    - 系统不再嗅探玩家措辞自动投骰。所有掷骰须显式触发：
      · 主持 主动：在回应中写 `<待检定 技能 目标 奖惩 "理由" />`，下轮引擎自动掷骰并回灌结果
      · 玩家主动：直接打 `/投 技能 目标 [奖惩]`（目标可省，自动取该技能当前等级）
      · 失败翻盘：打 `/幸运 [数量]`（默认恰够翻盘的花费）或 `/强投`（带 1 惩罚骰重投）
    - 引擎掷 d100、判档，结果写入 stat_data._rollLog（前端状态栏/检定录簿可查阅）
    - 主持 在叙事中嵌入标注格式 `【检定｜技能名 XX｜投出 YY｜结果】`，正则将其渲染为骰子卡给玩家看
    - 心神 检定：写 `<待检定 心神 55 "1/1d3" />`，理由位填"成功损失值/失败损失值"；引擎附掷损失骰并提示失魂发作
    - 战斗命中：`<待检定 格斗(摔) 60 "出招"/>`；伤害由 主持 按 斗战规则 另掷 1d3/1d6+db 并写入 气血 delta
    - 不得改动主动写出的"投出值"；翻盘/重投须让玩家用 `/幸运` `/强投`，引擎再行投骰
