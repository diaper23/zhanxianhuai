### 七十条剧情暗线

从穿越逼婚的第一夜，到方山血案、天牢逼宫、谯郡暴动、汉中决战、弑君富春山——整条架空东晋乱世的命运线被拆成**七十个剧情节点**，全部接入EJS剧情系统。

每一节点都有自己的**触发条件**：有的看你身在何方，有的等你在最近几楼聊天里提及了某个地名或人名，有的纯看天意掷骰。触发了，系统才把它作为当前回合的副线或明示目标送进AI；没触发，AI根本看不到——不会因为你这局没走方山线就被王劭的往事塞满。

剧情不再是一条线，而是一张沙盒网。你可以按推荐路线一步步推进，也可以故意绕开主线，让伏笔沉默、让势力错过，走出属于你自己的历史偏移。

**六大语义层各自管控不同干涉强度：**

- **禁令（5条）**— 永久生效的红线。穿越者身份不可泄露、未来正史不可灌入、远方人物不可瞬移登场、战场煞气压制武林高手……AI在思考链和正文里都必须绕开这些。
- **覆盖（3条）**— 当危机临界时劫持叙事焦点。谢秋瞳决意杀人、身份严重暴露、喜儿动手——触发后本回合叙事必须以此为轴。
- **插入（70条）**— 副线剧情。自然汇入当前流，不生硬中断你的行动；若你的输入与插入矛盾，以插入为准并用剧情逻辑圆场。
- **线索（4条）**— 可追查的浮出之谜。线索必须由具体载体抛出（NPC失言、密信、账册、暗号），不能由旁白直接点名真相。
- **明示（5条）**— 贴脸危机预告。五感描写把紧迫感推到眼前，但保留最后一丝悬念，不替你掀盖头。
- **暗示（4条）**— 草蛇灰线。只在环境侧写里留下隐晦的痕迹——屋脊瓦片轻响、甜腻毒粉气味、巷尾一闪而过的短小身影——不点名喜儿是谁，除非剧情已发现她。

### 三位红颜，十七个感情阶段

不再是几行好感数字决定一切。本次重写为谢秋瞳、喜儿、王徽各自落地了**多阶段动态人设**，AI收到的是当前阶段对应的语言风格、行为倾向和内在拉扯——上一阶段还有限合作，这一阶段可能就情感动摇，语言都不一样。

**谢秋瞳（5阶段）**：陌生试探 → 有限合作 → 情感动摇 → 深层信任 → 决裂敌对  
她是建康第一女魔头，每一段进程都像在走钢丝。冷淡精确地评估你的价值；以赌约为名在交锋中摸底；不再设防核心信息但好胜心让她逞强；将你视为超越盟友的存在但咳血时第一个想见你——又或者，桌上的茶突然就凉了。

**喜儿（6阶段）**：暗处观察 → 目标接触 → 交易保护 → 情感动摇 → 归属确认 → 背叛危机  
圣女匕首下藏着的小姑娘，从蹲在唐家屋脊远远看不到脸，到认定你值得以命换命，到师门逼她把刀抽出来——她会故意说"骗子""我早知道"，真正难过时反而不吵，只低头擦刀。

**王徽（6阶段）**：未相识 → 好奇 → 欣赏 → 同行 → 倾心 → 失望  
门阀明珠被王导当联姻筹码。她把喜欢放进责任、选择和现实后果里思考。你可以走到倾心，但若你让她看到的是你身上的选择代价，她也会把答案封进书页里——不吵，只送别。
