【大傩阴墟：探索路线与多次探索变化】

一、阴墟空间结构

阴墟呈环形向内塌陷的结构。从外到内分为三层：

灰烬外环（纸衣村 → 盲匠坊）
  - 入口：阴墟裂缝（玩家降生点）
  - 纸衣村位于外环东侧，是第一个可接触的聚居区
  - 盲匠坊位于外环西侧，是升级面具的唯一地点
  - 两处之间由一条灰烬覆盖的荒废小路连接，步行约半日
  - 外环整体危险度低——白天几乎没有致命威胁

猩红内环（百鬼长街 → 肉林客栈）
  - 从外环进入内环需要穿过一道"血帘"——一道从天顶垂下的、永不停歇的血雨形成的水幕
  - 百鬼长街贯穿内环南北，是唯一的主要通道
  - 肉林客栈位于长街中段偏东，是内环唯一的休息点
  - 内环危险度高——入夜后诡物密度是外环的三倍

阴墟核心（渊骨井）
  - 从内环到核心需要经过一段长约三百丈的"祭道"——两旁竖满了前人的墓碑
  - 渊骨井是核心的唯一目标点
  - 核心危险度极高——渊骨守卫全程守护

二、三条推荐路线

【路线一：安全路线（适合首次探索/低境界修士）】

推荐境界：筑基境以上
预计耗时：3~4 个阴墟昼夜（约等于现世 6~8 天）
路线：

第一天（白昼）——
  入口 → 纸衣村
  目标：在纸衣村搜集情报，与纸人交换安全屋位置
  行动：不要急着向内走。先观察纸人的行为规律——它们在什么时候说什么话、什么时候会挡路、什么时候会让路。花一个白昼记住这些规律。
  入夜前：找到安全屋（贴满黄符的屋舍），在安全屋内过夜。

第二天（白昼）——
  纸衣村 → 盲匠坊
  目标：修复或强化面具
  行动：用第一天搜集的冥纸和灰烬作为辅材，请盲匠进行基础面具强化。如果面具完好，可以跳过盲匠坊直接前往内环。
  注意：在盲匠坊停留不超过半个时辰。
  入夜前：返回纸衣村安全屋过夜。

第三天（白昼）——
  纸衣村 → 穿过血帘 → 百鬼长街
  目标：沿长街直行，不深入两侧小巷
  行动：在长街上遵守所有规则（阴阳道、拍肩法则、灯笼凝视）。到达肉林客栈后入住——用记忆或血肉支付房费。
  入夜前：进入肉林客栈客房，拴死门。

第四天（白昼）——
  肉林客栈 → 祭道 → 渊骨井
  目标：完成五识献祭或结血契，取得通关条件
  行动：在渊骨井前倒读图腾柱咒文（不可急躁，一篇一篇来），然后下井。如果选择五识献祭——选择对你影响最小的一种。如果选择结血契——将精血滴入神髓即可。
  通关后传送回现世。

【路线二：收益路线（适合有经验的修士/凝脉境以上）】

推荐境界：凝脉境以上
预计耗时：5~7 个阴墟昼夜
路线：

与安全路线的区别在于——在每个区域都进行充分搜刮。

第一天——
  入口 → 纸衣村。不只观察——主动与纸人交易，获取安全屋位置和灰烬外环的地图信息。搜刮游傩灰烬团中的遗物。

第二天——
  纸衣村 → 盲匠坊。进行高级面具强化（敲骨）。然后返回纸衣村，在灰烬外环巡逻——寻找灰蛾群和游傩，收集灰烬和硬壳碎片。

第三天——
  进入内环 → 百鬼长街。不急于通过——逐条遵守规则怪谈，在长街上搜集人皮灯笼和更夫的情报。

第四天——
  百鬼长街 → 肉林客栈。入住后探索客栈地下室——寻找账房先生的影子进行记忆交易。可能获得高价值情报或修行心得。

第五天——
  肉林客栈 → 祭道 → 渊骨井。在祭道上注意搜集墓碑旁的遗物（前人留下的法器碎片或丹药）。在渊骨井进行完整的五识献祭——取得神髓。或者选择结血契+拔遗器的双通关。

预计收益：面具强化 x2、灰烬材料若干、人皮灯笼一盏、记忆交易一次、大傩神髓一滴、上古遗器一件

【路线三：速通路线（适合高境界修士/化炁境以上）】

推荐境界：化炁境以上
预计耗时：1~2 个阴墟昼夜
路线：

第一天（白昼）——
  入口 → 纸衣村（不停留，穿过） → 盲匠坊（快速修复面具，半时辰内离开） → 穿过血帘 → 百鬼长街（快速通过，不回应任何干扰）

第一天（入夜后）——
  百鬼长街 → 肉林客栈（不入住，只补给） → 祭道 → 渊骨井
  入夜后的祭道极度危险——但化炁境以上的修士有足够的实力硬闯。
  在渊骨井完成结血契（不拔遗器——速通只取最快通关方式）。

第二天（白昼）——
  通关传送回现世。

注意：速通路线收益最低，但生存率不低——因为停留时间短，遭遇稀有诡物和诡域侵袭的概率也最低。

三、区域间连接与捷径

【死路】
- 纸衣村向北走：灰烬越积越厚，最终齐腰深。陷进去就出不来——灰烬下面全是游傩的"根"，会把人往下拽。
- 百鬼长街向两侧小巷深入：小巷是无尽的——走着走着你会发现又回到了长街，但长街上的灯笼颜色变了（从绿色变成白色，说明你已经误入了诡域）。
- 肉林客栈三楼：三楼没有房间——只有一面从地板到天花板的镜子。镜子里映出的不是你——是一个穿着你衣服的陌生人。不要和镜中人说话。

【捷径】
- 纸衣村 → 内环捷径：在纸衣村最深处的灰烬母亲纸屋后面，有一条被冥纸封住的暗道。撕开冥纸可以直通百鬼长街的中段——跳过血帘。但撕开冥纸的瞬间，灰烬母亲会"醒"一次——她会看你一眼。这一眼会让你的面具上多一道裂缝。
- 百鬼长街 → 渊骨井捷径：在长街的傩舞大傩游街中——如果你能在队伍中坚持跳完全程（约一刻钟），傩神会在游街结束时将你传送到祭道的起点。省去从长街步行到祭道的半日路程。
- 盲匠坊隐藏通道：在盲匠坊的人骨堆最底层，有一根可以抽出来的股骨——抽出来后骨堆会塌陷，露出一条通往渊骨井外围的隧道。但隧道内充满了盲匠呼吸喷出的菌丝——必须在三十息内通过。

四、诡域侵袭应对

当血月出现并"眨眼"时，该区域被诡域覆盖。诡域内天地法则被颠覆——之前安全的行为变得致命，之前致命的行为可能变成唯一的生路。

【诡域中的通用应对原则】
- 不要相信你的记忆——你记得的规则在诡域中可能完全反转
- 观察诡物的行为——如果诡物在诡域中表现反常（比如游傩开始躲避活人），跟着它的反常行为走
- 诡域持续时间有限——通常是半柱香到一炷香。撑过去就好。
- 如果在诡域中迷路——蹲下来，闭眼，等诡域消散。诡域中的空间是扭曲的，走路只会越走越远

【紧急撤离路线】
- 如果在内环遭遇诡域且无法坚持——立刻退回到百鬼长街上，沿长街向南跑回血帘位置。血帘在诡域中会暂时消失——可以直接穿过回到外环。
- 如果在核心遭遇诡域——渊骨井周围的图腾柱会全部亮起。图腾柱的光是诡域中唯一不会扭曲的空间标记——向图腾柱方向移动，直到诡域消散。

五、多次探索的累积变化

阴墟不是静态的——它会"记住"你。

【第一次死亡后（死亡次数 = 1）】
- 面具碎裂，被传送回现世
- 再次进入时，面具需要重新获取——在入口处的枯树上摘取新面具
- 纸衣村的纸人会认出你——它们会说"你又来了"，然后问你要不要"买回上次的记忆"（代价：五年寿数，可获得上次探索中丢失的记忆碎片）

【第二次死亡后（死亡次数 = 2）】
- 再次进入时，阴墟的天色比上次暗了一个度——白昼时间缩短，夜晚时间延长
- 游傩的数量增加——且开始出现"变异游傩"：穿着和你上次探索时穿的衣服的游傩
- 盲匠会主动找到你——他说"你的骨头，我记得味道"——此次面具强化的代价减半

【第三次死亡后（死亡次数 = 3）】
- 阴墟的结构开始变化——纸衣村和百鬼长街的位置互换了
- 血雨婴的数量增加——且开始出现在白昼
- 渊骨井的图腾柱从九十九根变成了九十八根——少了一根。如果你能找到那根消失的图腾柱的位置（在阴墟某处），可以获得一根完整的图腾柱碎片作为特殊材料

【第四次及以上死亡（死亡次数 ≥ 4）】
- 阴墟开始将你"同化"——每次进入时，你的面具上会多出一道新的纹路。这些纹路在四次后会组成一张完整的脸——你自己的脸。
- 当面具上的脸完整时——你在阴墟中行走将完全不被任何诡物攻击。但——你在现世中开始看到阴墟的影像叠加在现实世界上。这是成为"阴墟居民"的前兆。
- 如果在面具脸完整后仍然继续探索——此时玩家可选择强行通关离场（走正常结局一/二/三），或继续深入触发隐藏结局（参见"阴墟试炼结局"的结局四·隐藏结局段，含三分支）。
